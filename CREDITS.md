# Asset credits and notes

- **Photography:** Free Unsplash images displayed remotely using `images.unsplash.com` URLs. The site features editorial/lifestyle stock photographs, not product-pack photography. Individual image IDs are listed in `products.js` and `index.html`. Photo sources: https://unsplash.com/ — usage subject to https://unsplash.com/license. Attribution is appreciated by photographers, though not mandatory for standard Unsplash free photography.
- **Icon system:** Font Awesome Free 7.3.1 from cdnjs: https://fontawesome.com/license/free (icons are subject to applicable Font Awesome licensing).
- **CSS library:** Bootstrap 5.3.9 from jsDelivr: https://getbootstrap.com/ (MIT License).
- **Fonts:** DM Sans, Manrope and Playfair Display from Google Fonts, covered by the respective open-font licenses.
- **Custom code:** HTML, CSS and JavaScript for this demonstration were assembled for this project.

No external photos, fonts or Bootstrap files are bundled locally; internet access is required for them to load. An original SVG fallback (`image-fallback.svg`) and favicon are bundled for offline resilience.
